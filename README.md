EduGenie – Google Gemini Powered Learning Assistant

Project Overview
EduGenie is an AI-powered educational learning assistant designed to help students learn concepts easily and effectively using Google Gemini AI models. It allows users to ask academic questions, understand complex topics through simplified explanations, generate quizzes, summarize educational content, and receive personalized learning recommendations.
